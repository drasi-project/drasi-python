Each guide covers one job:

- **[Python sources](python-sources/)** — push your own changes into the engine.
- **[Python reactions](python-reactions/)** — handle result diffs, including durable
  reactions that survive a restart.
- **[Streaming results](streaming/)** — consume results, events and logs as async
  iterators.
- **[Plugins](plugins/)** — search, install, verify and load native Drasi plugins.
- **[Error handling](error-handling/)** — the typed exception hierarchy and error codes.
- **[The blocking API](blocking-api/)** — `drasi.sync` for scripts and notebooks.
- **[Typing](typing/)** — the shipped type stubs and how to use them.
